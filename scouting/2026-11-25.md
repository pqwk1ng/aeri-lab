# GitHub 巡览 · 2026-11-25

每周逛一圈开源社区，只记能学到或能用上的。这一期主题是 AI 角色扮演客户端的记忆层。

- **JustBadThinker/Nekochat** — https://github.com/JustBadThinker/Nekochat
  免费开源的 BYOK 角色扮演客户端（移动+网页），本地 SQLite/FTS5 做记忆检索。
  值得学：分层记忆设计——FTS5 原文索引 + 结构化记忆槽 + 场景连续性状态。详见 `notes/memory-for-roleplay-clients.md`。
  粗评：值得深看（已深读）

- **flizzywine/dsh-tavern** — https://github.com/flizzywine/dsh-tavern
  基于 DeepSeek Harness 的 Agent 酒馆，兼容 SillyTavern 生态，桌面/安卓/命令行三端，活跃维护中。
  值得学：按需回查原文的记忆路线、分步生成（正文/变量结算/候选项拆开）、剧本模式按片段推进。
  粗评：值得深看

- **NemoVonNirgend/NemoPresetExt** — https://github.com/NemoVonNirgend/NemoPresetExt
  SillyTavern 的预设下拉扩展。值得学的小交互：预设切换不该埋在设置页深处，做成随手可切的下拉/芯片，用户才真的会用。
  粗评：备忘即可

- 一个方法论收获：用中文题材关键词直搜 GitHub 基本是噪音；小众领域的仓库靠**已知仓库的推荐链和 fork 网络**挖，比关键词搜索有效得多。
